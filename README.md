# 하루 업무 관리

날짜별로 업무를 등록하고 완료 여부를 체크하는 작은 업무관리 프로그램입니다. 미완료 업무의 이월, 전체 데이터 백업과 복원을 지원합니다.

## 첫 실행

1. `index.html`을 PC에 저장합니다. GitHub 파일 화면에서는 **Download raw file**로 다운로드합니다.
2. 저장한 파일을 더블 클릭하여 최신 Chrome 또는 Edge에서 엽니다.
3. 날짜를 선택하고 업무명·메모를 입력한 뒤 **업무 추가**를 누릅니다.

별도 설치, 로그인, 서버, 인터넷 연결 없이 실행됩니다. `index.html` 하나에 화면·스타일·실행 코드가 모두 들어 있습니다. HTML 코드를 표시하는 미리보기 대신, 다운로드한 파일을 브라우저에서 열어 주세요.

## 사용 방법

| 기능 | 사용 방법 |
| --- | --- |
| 날짜별 등록 | 위쪽 날짜를 선택한 후 업무 등록 |
| 완료 체크 | 업무 왼쪽 체크박스 선택. 다시 누르면 진행 중으로 변경 |
| 이월 | 진행 중 업무의 **이월** → 이후 날짜 선택 → **이월 처리** |
| 이월 기록 | 원래 날짜에서 이월 날짜 확인. **현재 업무일 보기**로 이동 |
| 수정·삭제 | 해당 업무의 버튼 사용. 삭제 시 해당 업무의 이월 기록도 삭제 |
| 필터·검색 | 선택한 날짜 안에서 진행 중·완료·이월 또는 업무명·메모 검색 |
| 백업 저장 | 모든 날짜·완료 상태·이월 기록을 JSON 파일로 다운로드 |
| 백업 불러오기 | 정상 백업을 선택하고 전체 데이터 교체 확인 |

이월은 업무를 복제하지 않고 날짜를 옮깁니다. 원래 날짜에는 이월 당시의 업무명과 메모가 남습니다. 완료된 업무는 체크를 해제한 뒤 이월할 수 있습니다. 자동으로 다음날 이월하지 않으며 원하는 날짜를 직접 지정합니다. 현황의 **전체**는 선택한 날짜의 진행 중·완료 업무와 이월 처리 기록을 합한 수입니다.

## 저장과 백업

- 입력한 업무는 같은 PC·브라우저의 `localStorage`에 자동 저장됩니다. 서버나 GitHub로 전송하지 않습니다.
- 브라우저 데이터 삭제, 시크릿 창 종료, PC 변경 시 기존 데이터가 사라질 수 있으므로 **백업 저장**을 사용해 주세요.
- HTML 파일의 이름·위치나 실행 주소가 바뀌면 브라우저가 다른 저장 공간으로 취급할 수 있습니다. 변경 전에 백업한 뒤 새 위치에서 불러오세요.
- 파일로 직접 열 때 자동 저장 지원 여부는 브라우저 환경에 따라 다릅니다. 저장이 막혀 있으면 안내가 표시됩니다. 임시 사용 중에는 닫기 전에 백업이 필요합니다.
- 백업 저장 위치는 브라우저 다운로드 설정을 따릅니다. 매번 폴더를 선택하려면 브라우저의 ‘다운로드 전에 각 파일의 저장 위치 확인’을 켜세요.
- **백업 불러오기**는 모든 날짜의 현재 데이터를 교체합니다. 필요하면 먼저 현재 데이터를 백업해 주세요. 잘못된 파일은 기존 데이터를 변경하지 않고 거부합니다.
- 기존 자동 저장 데이터가 손상되면 편집을 중지하며, **백업 저장**으로 손상된 원본을 보관할 수 있습니다.
- 동일 브라우저의 다른 창에서 발생한 변경을 감지하고 오래된 데이터를 덮어쓰지 않도록 확인합니다. 여러 창에서 정확히 동시에 저장하는 경우까지 보장하는 협업 도구는 아니므로 한 창에서 사용해 주세요.
- 이 저장소는 공개 저장소입니다. 소스 코드만 보관하며 실제 업무가 담긴 백업 파일은 커밋하지 마세요.

## 기본 구조

```text
index.html                첫 실행 파일: 화면 + 데이터 처리 + 저장/복원
package.json              개발용 테스트 명령 (외부 의존성 없음)
tests/core.test.cjs        날짜, 완료, 이월, 백업/복원 검증
.github/workflows/test.yml  GitHub에서 Node 테스트 실행
```

`index.html`의 `task-core` 스크립트는 화면과 분리된 순수 데이터 연산입니다. 테스트가 실제 실행 파일에서 해당 코드를 읽어 검증하므로 별도의 복제 코드를 관리하지 않습니다. 두 번째 스크립트는 화면 이벤트·자동 저장·파일 다운로드를 담당합니다. 입력 문자열은 `textContent`로 표시합니다.

데이터 형식은 `app: "daily-work-manager"`, `version: 1`, `tasks` 배열입니다. 업무마다 고유 ID, 업무일, 제목, 메모, 완료 상태, 생성/수정/완료 시각, 이월 기록을 보관합니다. 이 버전은 업무 최대 10,000건, 제목 200자, 메모 2,000자를 지원하며 복원 파일은 최대 20MB입니다. 이전에 만든 다른 업무관리 HTML 프로그램의 백업은 이 버전과 호환되지 않을 수 있습니다.

## 개발 확인

Node.js 20 이상에서 설치 과정 없이 실행합니다.

```sh
npm test
```

안정적인 고정 주소로 실행하고 싶다면 Python이 있는 PC에서 아래 명령을 실행한 뒤 `http://localhost:8000`을 엽니다. 파일로 열었을 때와 저장 공간이 다르므로 기존 데이터는 백업으로 옮겨 주세요.

```sh
python -m http.server 8000 --bind 127.0.0.1
```
